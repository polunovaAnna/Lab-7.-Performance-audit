# Звіт: аудит продуктивності «Каталог репетиторів»

## Умови вимірювання

- Машина: ASUS Vivobook (X1403ZA), Intel Core i5-12500H, 8 Гб ОЗП
- ОС: Windows (11 Home Single Language), версія 26H2
- Живлення: від батареї
- Браузер: Google Chrome 157.0.8103.79, вікно інкогніто, розширення вимкнені
- Збірка: `npm run build` + `npm run preview` (http://localhost:4173), Node (v24.15.0)
- Завантаження (Lighthouse): режим Navigation, Mobile, категорія Performance, стандартний (simulated) throttling Lighthouse
- Взаємодії (DevTools Performance, Live metrics): CPU 4× slowdown, Network Fast 4G, Disable cache
- Перед кожним запуском сторінка перезавантажується, один запуск = один сценарій
- Кількість запусків: 3, у таблиці медіана
